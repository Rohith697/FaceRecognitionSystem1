1. Executive Summary

Project Overview: The AI Face Recognition & Attendance System is an enterprise web application engineered for contactless identity recognition, automated attendance logging, and workforce management. Built using Java 25, Spring Boot 3, and OpenCV Computer Vision, the platform extracts facial feature vectors from video frames, executes similarity matching against stored MySQL templates, and provides an interactive Admin Control Portal for workforce metrics and account management.

Direct Link to Live Application: http://localhost:8080

2. Key Features & Functionalities

  • Real-Time Facial Identification: Captures live video streams via HTML5 webcam, extracts facial feature vectors using OpenCV OpenPNP (OpenPNP OpenCV 4.9.0), and calculates similarity matching with a 70%+ threshold.
  • Automated Attendance Logging: Automatically generates timestamped records in the MySQL attendance_logs table upon successful match verification.
  • User Enrollment & Face Training: Snapshot capture interface allowing new users to enroll with full name, email address, company/department, and instant facial embedding encoding.
  • Admin Control Center & Workforce Analytics:
    • Total enrolled users & company department statistics summary cards.
    • Visual grid displaying user distribution metrics per department/company.
    • Department filter dropdown for user directory inspection.
    • Update User: Modal dialog to edit name, email, and department (PUT /api/users/{id}).
    • Delete User: Instant deletion of user records from MySQL with foreign key cascading (DELETE /api/users/{id}).

5. Interactive REST API Specifications

Method Endpoint Request Payload Description
GET /api/health None System health status & enrolled user count.
POST /api/register { name, email, department, imageBase64 } Enrolls user, extracts face features, saves to MySQL.
POST /api/recognize { imageBase64 } Analyzes webcam frame & logs attendance.
GET /api/users None Returns list of all enrolled users.
GET /api/logs None Retrieves recent attendance recognition logs.
GET /api/admin/stats None Returns company metrics & department user counts.
PUT /api/users/{id} { name, email, department } Updates user details in MySQL.
DELETE /api/users/{id} None Deletes user account and associated attendance records.

6. Database Schema Design

Table 1: users

Field Name Data Type Constraints Description
id BIGINT PRIMARY KEY, AUTO_INCREMENT Unique User ID
name VARCHAR(100) NOT NULL Employee Name
email VARCHAR(100) NOT NULL, UNIQUE Email Address
department VARCHAR(100) DEFAULT 'General' Company / Department
face_features LONGTEXT NULLABLE JSON Array of Extracted Features
photo_base64 LONGTEXT NULLABLE Base64 Photo Snapshot
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP Registration Timestamp

Table 2: attendance_logs

Field Name Data Type Constraints Description
id BIGINT PRIMARY KEY, AUTO_INCREMENT Log Entry ID
user_id BIGINT FOREIGN KEY (users.id) User ID Reference
user_name VARCHAR(100) NOT NULL Matched Name
department VARCHAR(100) NULLABLE Company Department
confidence_score DOUBLE NOT NULL Match Confidence %
status VARCHAR(50) DEFAULT 'SUCCESS' Status Tag
timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP Access Timestamp
